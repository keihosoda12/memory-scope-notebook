# AIに何を覚えさせるかを選べるメモリ手帳（memory-scope-notebook）

AIアシスタントが会話から覚えたことを、ユーザーが「ずっと覚える」「今日だけ」「要確認」「捨てる」に分けて管理できる、小さなプロトタイプです。題材は献立など日常の会話です。

## 解く問題

AIアシスタントが一度言ったことを全部「その人の好み」として覚えてしまうと、今日だけの都合まで恒常的な好みとして扱われてしまいます。逆に何も覚えなければ、毎回同じ説明が必要です。このプロトタイプでは、記憶に「範囲（scope）」と「確信度」を持たせ、ユーザーが承認・修正できる形にします。

## 使い方

```bash
pip install -r requirements.txt
streamlit run app.py
```

画面では、サンプルの会話から抽出されたメモリ候補に加えて、自分の発話を入力して分類を試すこともできます。各候補は、分類（scope）の変更と文面の編集ができ、承認したメモリだけが提案に使われます。

ロジックだけの検証（Streamlit不要）:

```bash
python test_memory_logic.py
```

## 設計

- `memory_logic.py`: UIから独立したコアロジック。発話の分類（ルールベース）、承認済みメモリだけを使う提案生成、評価シナリオ（8件）を含む。
- `app.py`: Streamlitの画面。メモリ候補をカード表示し、承認・削除ができる。提案には「どのメモリを使ったか」の理由を必ず表示する。
- 外部LLM APIは使っていません。キーワードとルールで決定的に動くため、誰が実行しても同じ結果になります。

## 技術情報

- 言語: Python（研究でも日常的に使用）
- ライブラリ: Streamlit（画面）／コアロジックは標準ライブラリのみ
- 開発支援: AIツール（Claude等）を補助的に使用し、生成コードは評価シナリオで検証しています

## 限界（正直なところ）

- 分類はルールベースであり、実際のLLMによる抽出ではありません。言い換えや文脈依存の表現には弱いです。
- データは全て合成例です。実在の個人情報・企業内データは含まれていません。
- 提案は夕食候補の小さなカタログに対するもので、推薦精度の本格評価は今後の課題です。
